# `tests/test_autosar_spec_engine.py`

[Open source](../tests/test_autosar_spec_engine.py)

Uses a fake PDF reader and temporary files/database to verify incremental indexing, full-text search, Classic/Adaptive filtering, release and page citations, context formatting, and unchanged-file detection. It does not need the repository's real AUTOSAR PDF collection.

Run with `python -m pytest tests/test_autosar_spec_engine.py` when pytest is installed.
